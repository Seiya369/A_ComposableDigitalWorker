# 【演示资料】交互与知识阅读规范

这是体验设计示例，供评审布局与可读性，未声称真实用户研究已完成。

## 专业定义

工作流节点：以序号和步骤名称表达流程位置的交互元素。
步骤状态：区分待开始、进行中和已完成的状态。
知识图谱：展示重组后概念、实体和有依据语义关系的网络。
语义关系：有方向、谓词和资料依据的知识关联。
资料依据：可以定位到资料版本及原文行范围的引用。
交付契约：让负责人和用户共享相同完成预期的说明。

## 明确关系

工作流节点表达步骤状态。
知识图谱展示语义关系。
资料依据支撑语义关系。
交付契约关联资料依据。

## 布局与交互建议

步骤节点使用灰、蓝、白区分状态，始终保留全局序号。当前步骤在有限宽度窗口内保持可见；省略项打开详情，不能伪造被省略步骤之间的依赖。

步骤说明、交付记录、交付成果分别成组。条目标题保持简洁，长正文在只读详情内阅读。知识关系放在右侧资料详情中，完整展示源、谓词和目标；证据可以展开查看。

中英文切换只改变界面固定标签，不改员工名字、概念名称、文档正文、已选节点或未保存输入。窄屏优先保留正文空间，长标题省略时仍能查看全名。
