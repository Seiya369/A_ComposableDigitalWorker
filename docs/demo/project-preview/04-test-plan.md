# 【演示资料】测试方案与缺陷记录模板

此处只有计划和样例，没有真实执行的通过结果、覆盖率、性能数字或用户验收。

## 专业定义

测试计划：把范围、风险、环境、数据和验收标准分解成可执行检查的计划。
回归矩阵：按功能、状态、语言、尺寸和异常场景组织检查的清单。
缺陷记录：包含触发条件、复现步骤、预期、实际和证据引用的问题记录。
缺陷复测：依据原复现步骤核对修复，并检查受影响路径的活动。
验收标准：用于判断交付是否满足目标的可观察条件。
步骤状态：工作流中待开始、进行中和已完成的区别。

## 明确关系

测试计划分解验收标准。
回归矩阵覆盖步骤状态。
回归矩阵产生缺陷记录。
缺陷复测核对缺陷记录。
