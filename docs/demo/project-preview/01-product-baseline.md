# 【演示资料】产品范围与需求基线

本资料是界面演示用的人工示例，不代表真实业务决定或已经验收的需求。

## 专业定义

需求基线：描述目标用户、问题、范围、优先级和待确认问题的版本化约定。
交付契约：描述每一步的负责人、输入、交付内容和验收标准的约定。
验收标准：以可观察结果描述完成条件，避免使用“体验良好”等无法核对的说法。
步骤交付：负责人提交的结果说明、文档快照或项目内文件引用。
负责人：组织当前步骤并对交付完整性负责的岗位。

## 明确关系

需求基线定义交付契约。
交付契约包含验收标准。
验收标准约束步骤交付。
负责人组织步骤交付。

## 演示范围

拟提供工作流步骤导航、步骤说明、交付记录、交付成果和项目知识库入口。自由职业人库维护岗位能力，团队维护组织关系，项目工作流采用独立快照。

本示例不包括自动付款、真实上线、外部消息发送和无授权的跨项目访问。需求变化需记录影响范围，再修改相关输入、交付契约和验收标准。

## 计划中的验收点

1. 能区分未开始、当前步骤和已经完成的步骤。
2. 从当前步骤打开对应交付内容，原文和来源可追溯。
3. 没有真实验收记录时，不把候选事项标成已确定。
4. 专用演示流程不改动真实流程的状态或数据。

以上是演示计划，未在此文档中声明任何测试已经执行。
