# 【演示资料】发布与运维交接

本文是候选发布材料示例，不代表已经部署、安装、卸载或完成回滚演练。

## 专业定义

发布清单：列出版本、归档、依赖、变更说明和待核对事项的交接索引。
候选成果：尚需依据验收标准复核的文档或产物。
归档校验：用摘要把实际归档字节与指定版本绑定的核对。
回滚方案：说明恢复入口、数据兼容前提和异常处理的计划。
用户数据：用户项目文件、真实会话、凭据和已经交付的成果。
交付契约：定义交付物及其完成条件的约定。

## 明确关系

发布清单索引候选成果。
发布清单包含归档校验。
回滚方案保护用户数据。
候选成果遵循交付契约。

## 待核对清单

候选归档名使用实际构建版本，不在演示文档中编造 SHA-256。交接前应从实际文件计算摘要，记录兼容范围与安装路径，并在独立官方 profile 验证。

普通卸载保留恢复所需数据；完全清理只针对插件自有路径。停止服务后再执行一次性演示种子脚本，通过 revision、写入锁和原对象比对防止覆盖其他操作。

本演示不修改宿主程序、宿主数据库、原生会话事件、其他插件或真实项目成果。
