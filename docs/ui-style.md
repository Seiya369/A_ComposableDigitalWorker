# 界面样式约定

数字员工界面沿用 DeepSeek Harness 设置页的字体、控件尺寸和主题语义。样式最初参考 **0.1.1-rc.2**；下方源码链接保留相邻旧检出以追溯视觉依据。当前兼容宿主已升级为 **0.2.1-alpha.2**、提交 `d743267388641bc76f17c45ce8b4c231aed1d32c`，并通过浅色、深色和窄屏专项回归。新版接口差异见 [架构说明](../integration/architecture-0.2.1.md)。

## 主题与字体

宿主 [`ui-theme`](../../deepseek-harness/packages/client/ui-theme/src/styles/) 拥有浅色、深色和跟随系统的主题状态。插件在 [`workforce.css`](../src/ui/workforce.css) 的 `.wf-root` 中将本地变量映射到 `--dsw-alias-*`，组件不另设主题选择器或固定调色板。

字体使用 `--dsw-font-family`。正文与侧栏使用 `--dsw-font-s-14`（14/22），标签页使用 `--dsw-font-xs-13`（13/20），辅助信息使用 `--dsw-font-xxs-12`（12/18）。表单标签与控件按宿主插件设置页使用 13px、1.5 倍行高，由 `--wf-font-label` 与 `--wf-font-control` 统一定义；标签字重为 500。

页面标题由 `--wf-font-heading` 定义为 18px、字重 600，依据宿主插件设置标题；没有对应的 18px 字体 token。宿主 `--dsw-font-m-18` 实际为 16/28，不用于此标题。

| 表单字段 | 标签与控件间距 6；输入与选择框外高 36、圆角 8、水平内边距 12、layer-3 背景 | [fields.module.css](../../deepseek-harness/packages/client/ui-settings-plugins/src/client/fields.module.css) |

| 常规按钮 | 36px 高、圆角 18、14/22、水平内边距 14 | [Button.module.css](../../deepseek-harness/packages/client/ui-primitives/src/Button.module.css) |
| 紧凑按钮 | 28px 高、圆角 14、12/18、水平内边距 10 | 同上 |

宿主插件输入框声明 `height: 34px`，采用内容盒模型，加上上下边框后外高为 36px。插件统一使用 `border-box`，因此 `--wf-control-height` 为 36px，按实际外观对齐。多行输入按内容扩展；搜索框等紧凑控件可采用宿主对应场景的尺寸。

不同尺寸集中在 `.wf-root` 的 `--wf-font-*`、`--wf-control-*` 和 `--wf-card-radius` 中。组织图、项目组队和员工四页表单共用这些基础规则，布局可按自身内容调整，保持可见焦点、禁用态与窄屏滚动。

## 复用边界

宿主 [`ui-primitives`](../../deepseek-harness/packages/client/ui-primitives/src/index.ts) 公开 Button、Input、Pill、Menu、Modal 和图标等组件；没有公开的通用 Select、Tabs 或 Toggle。插件遵循这些组件的样式契约，不导入宿主设置页的内部组件或内部 CSS Modules。

移除、删除及归档等操作的文字与图标使用宿主原主题红色 `var(--wf-red)`（`.wf-danger-text`），跟随深浅主题。团队与岗位的移除使用浏览器确认框，取消不修改草稿或持久数据。

新增样式先核对宿主对应场景，使用已有语义 token；职责由插件拥有的控件组合留在插件内。宿主升级时同步核对上述来源与盒模型，避免仅复制声明数值而造成尺寸偏差。宿主完整规则见 [web-styling.md](../../deepseek-harness/docs/web-styling.md)。

## 员工设置密度（2026-10-22）

员工页保留四个页签。品牌和三个库的导航保留在页头；自由职业人、团队和工作流的对象标题行右侧统一放置移除、导入、导出和保存。自由职业人的移除仅对已保存模板可用，提示保留配置与项目实例；新建草稿按钮禁用，项目员工不显示库移除。取消还原按钮及全局范围、JSON、刷新操作，离开时保留放弃草稿确认。该页面的姓名输入与操作按钮采用 32px 高度，操作组可在窄屏换行；页签 36px，字段标签间距 4px，正文区域内边距 12px/16px。规则限定在员工页面，不修改宿主控件。

员工库及未分组员工列表直接复用团队成员的紧凑单行样式，使用 14px 人形图标及姓名，行高至少 32px；不显示头像框和第二行草稿／版本，长姓名单行省略并提供完整姓名悬停提示。

团队页左侧成员树及组织图只展示，不提供点击配置、拖动或成员键盘焦点；团队标题仍可选择和展开。主区标题支持直接编辑团队名称，下方标注“组织结构”；删除组织／工作流页签和设置齿轮。资料管理员以员工同尺寸、同灰色的紧凑开关放在标题栏右侧，取消添加员工按钮、底部操作栏及团队“还原修改”。资料管理员、移除、导入、导出与保存集中于标题栏右侧；未保存状态保留在该行，确认放弃后离开恢复已保存内容。引入行只保留“选择要引进人员”和引入按钮。岗位使用两张一行的紧凑卡片，每张包含“团队岗位”“上一级”和红色移除；窄容器改为单列。开关随团队草稿保存。三个模板页面顶部均取消通用模板／项目实例切换、全局导入导出及刷新；对象级导入导出位于各自操作栏，项目通过原生会话团队配置进入。

页签依次为模型配置、岗位定义、能力组合、认知记忆，点击员工默认打开模型配置。岗位角色标签行右侧提供紧凑“AI智填”，按钮右边缘与输入框一致，三个岗位标签行等高，保留三块正文均分布局。对象导入读取期间暂停同一编辑器的表单、保存与移除；导入失败提示位于操作区域且不覆盖表单。标题操作可随可用宽度换行，不能遮住姓名、表单或导航。生成中按钮显示“填充中…”并阻止重复提交；错误在行内显示，表单仍可编辑，迟到结果不能覆盖后续编辑。专业知识“上传资料”及三个“自动归档”的文字使用与图谱统计一致的主题灰色（浅色 `#697585`、深色 `#adb0b6`），不改变卡片标题及开关状态颜色。

知识页的概念／实体语义图谱与正文在各自区域滚动，四类来源保持可见；窄屏允许分类换行，姓名栏操作换行。首项为“专业知识”，右侧“上传资料”打开原有专业资料窗口；任务档案、复盘经验、工作约束右侧各为开关及“自动归档”，开关独立且有清晰焦点与状态。卡片本身不作图谱筛选或跳转，不加用途注释和数量。图谱节点统一缩小半径并保留语义度数比例，默认“知识分组”着色并展示分组图例，可切换“节点类别”查看概念／实体图例，统计仅概念数、实体数和原始语义关系数。顶部删除“文章”按钮；来源、B 文章和概览不画为节点，从概念进入关联文章和右侧证据阅读；旧无概念图但已有文章时自动打开只读目录。浅色、深色与窄屏以独立官方宿主的浏览器验收为准。

图谱默认显示二维分组总览：多个语义连通组在同一画布紧凑排布，浅色包络和组名只作阅读引导，不引入分类节点或关系。选中概念后突出其一跳邻居，其余节点淡化且仍可见；沿概念阅读文章和原始证据时保留焦点。搜索回车定位概念，清空搜索和换库解除焦点，换库恢复默认分组着色；适配操作回到总览。图谱与阅读面板在深浅色、窄屏和矮窗下均不得遮住缩放、关闭或来源操作。

岗位定义页的三个字段以相同 flex 比例平分正文可用高度，输入框在字段内伸展且各自滚动。三个字段的最小组高度为100px，表单最小高度328px（含两处14px间距）；窗口较矮时由正文容器滚动，避免输入区被压扁。

## 工作流步骤编辑（2026-10-24）

工作流侧栏复用自由职业人库的单行图标与名称样式，保留完整名称悬停提示，不显示岗位数、步骤数或版本副行。标题行保留可编辑名称及移除、导入、导出、保存，与员工同样使用紧凑控件和窄屏换行；不增加四维度页签。

主区直接显示步骤卡，编号与名称、负责人置于顶部，下面为步骤说明和验收标准。验收标准使用逐行编辑的多行框；添加步骤、上移、下移和确认移除集中在步骤旁。独立流程岗位管理、工作流说明、输入输出、重试与超时不显示在基本编辑区，历史值保留。引入团队位于侧栏按钮，使用带焦点管理、Escape 关闭和内部滚动的模态框，映射项只列步骤引用的负责人。
