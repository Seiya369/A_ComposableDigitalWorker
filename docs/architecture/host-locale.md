# 跟随 DSH 的界面语言

插件界面使用 DSH 原有语言设置。DSH 选择中文时显示中文，选择 English 时显示英文；插件没有单独的语言选择器、偏好字段、本地存储或语言写接口。员工名称、角色正文、工作流与步骤名称、专业资料、概念和模型生成内容保持原文，切换界面语言不会翻译或重新生成这些数据。

## 官方依据与运行方式

适用 DSH 0.2.1-alpha.2。使用已声明的 `@deepseek-ai/dsh-client-locale/client` 公开服务：`register(namespace, locale, dict)` 注册本插件中英词典，`bind(namespace)` 获取翻译函数，`getSnapshot`/`subscribe` 订阅 DSH 当前语言及注册语言的 fallback 链。公开声明位于官方包 `lib/types/client/index.d.ts`。没有读取宿主私有状态、修改宿主界面、调用 `setLocale` 或扩展设置页。

所有资源库 main、单条交付 main、对话选择器、顶部步骤和交付底栏在各自的公开插槽内使用 React Context 订阅同一语言服务。语言变化更新原组件，不通过重新挂载、刷新页面或更换编辑器 key 实现，因此不会丢失未保存表单、验收说明或当前查看的步骤。固定文案及可识别的 API 错误在显示时翻译，动态名称以参数原样代入；未知外部错误保留原始诊断，不把内容误当作界面文案改写。

知识图谱使用独立许可证和沙箱 iframe。父组件在原有绑定 init/update 消息中增加 `locale: 'zh' | 'en'`；iframe 校验白名单，旧消息缺省中文。不改变 channel、epoch、spaceId、version、来源校验或读权限。语言变化不会清除图谱布局、搜索、所选节点、打开的文章或进行中的来源读取，也不会触发模型整理。

## 文案维护与生命周期

主界面词典位于 `src/ui/locales/`，`src/ui/i18n.tsx` 统一处理参数、错误和 fallback。图谱独立词典在 `third_party/llm-wiki/web/i18n.tsx`，不依赖主程序 React 实例。新增固定 UI 文案必须提供中英文，按钮正文、提示、确认框、无障碍名称和空状态均纳入检查。

使用 Cordis effect 持有词典注销函数；注册中途失败会回滚已注册的本插件词典，重复注销安全。卸载时组件订阅和图谱监听随各自作用域清理，词典注销；DSH 的语言选择及用户数据不受影响。测试覆盖词典键和参数一致性、原生设置实时同步、草稿保护、iframe 协议与原文保护，以及归档安装卸载。
