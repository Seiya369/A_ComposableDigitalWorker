## 验收场景

1. 两个任务依赖同一已验收前置任务，可独立执行；阻塞任务不提前启动，暂停阻止新派工。
2. 上游成果修订后，旧验收和受影响下游显示需复核；无关任务保持原状态。
3. 退回、重试、换人保留任务身份及所有执行尝试；成果和验收绑定版本。
4. 只有项目必交成果均在当前有效版本通过验收时，才允许确认项目完成。
5. 工作台、列表和 Graph 状态一致；可以不用拖拽完成管理，窄屏可读可操作。
6. 旧人员、模板、流程、记录与模型单选行为保留；升级不自动调用模型或放宽权限。
