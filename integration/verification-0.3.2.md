## 岗位模型约束

主流程报告：最终 build、typecheck 及 130 项领域/运行测试通过。本版直接显示 DSH 全部可用模型，按提供方分组并使用单选框；旧 `inherit` 保留读取兼容，在界面中视为未选择。每个职业人运行前必须明确选择模型，执行器不再读取来源会话、项目模型或宿主默认值作为回退；同时移除本插件对 `dsh-agent-default-model` 的直接注入、导入与 peer 声明。

升级不自动迁移用户模板或实例。现有 `inherit` 记录需要用户自行选择模型后才能运行。本轮不调用真实模型完成任务，也不验证外部账号的模型推理可用性。模型与凭据仍由 Harness 管理；插件只保存所选 provider/model/reasoning 标识，目录读取采用官方服务。

## 清理安全边界

针对性测试另验证了：预览只读、CLI 尚未 remove 时不删数据、自定义 statePath 需要完全匹配的显式归属声明、其他 profile 共享状态拒绝删除、非插件格式/符号链接/硬链接/过期计划拒绝删除、保留其他插件配置及其嵌套业务内容、不删除依附本插件 id 的其他插入配置。

原生员工会话作为宿主共享历史保留；本验收不声称抹除宿主历史痕迹，也不手工修改共享 session/credentials 存储。自建服务和日志清理由显式 `--service-root` 定位，临时目录测试覆盖其专属日志删除；本次生命周期没有创建或移除真实用户的 launchd 服务。后续若随包文件改变，必须重新打包并绑定新哈希重新验收。
