## 项目详情行为

详情标题读取真实项目名称，工作流名称在步骤区独立展示。界面提供“工作流”和“项目知识库”页签；知识库沿用当前冻结工作流的项目团队知识空间。没有有效知识目标时禁用入口，读取响应必须匹配请求目标，不以其他团队或全局模板代替。

右侧按“步骤内容 → 交付记录 → 交付成果”排列。步骤内容显示说明、交付要求、验收标准、负责人及其下级，以及有效退回目标。左侧只画冻结定义中明确配置且目标存在的退回路径；未配置的步骤不会被补成默认自环。右侧仍说明未配置时重试本步骤的既有有效规则。

浏览步骤、历史交付、成果正文或知识库均不激活步骤、不委派人员、不启动模型。只有明确点击“设为当前”或验收按钮才进入原有写入入口；负责人、共享进度及验收 CAS 规则保留。

所选步骤的交付列表只包含本冻结实例、该步骤负责人产生的根交付，按最近优先显示，返回数量与总数分开记录。历史交付读取可携带 `stepId/runId/runVersion`；版本失效返回冲突并要求刷新，不自动读取另一版本。旧调用未提供版本时保持兼容，原对话历史独立交付继续受原有归属限制。

成果文档展示保存的只读文字快照，超限内容显示截断标识与原长度。路径只是显示字段，不作为读取本机文件或任意 URL 的依据；无文字快照时明确提示不可预览。正文以文本展示，不执行 HTML、脚本、Markdown 链接或文件中的指令。

## 事项声明与验收出处

可选 `*.confirmed-items.json` 文件在原有权限与受限 UTF-8 快照读取成功后使用媒体类型 `application/vnd.composable-workforce.confirmed-items+json`。结构为：

```json
{"schemaVersion":1,"items":[{"id":"scope","title":"范围声明","content":"该交付声明的事项内容。"}]}
```

解析限制为文档不超过 100,000 字符、最多 50 项、ID 唯一且不含首尾空白或控制字符，ID／标题／正文分别不超过 120／240／20,000 字符。未知字段、非法 JSON、错误类型和越界结构不提升为事项，原 artifact 仍能作为普通文档查看；跨文件合计超出 50 项也不做部分提升。

只有当前有效完成记录引用、项目／实例／步骤／负责人匹配、状态成功、已验收且验收时间精确匹配的交付，才能供给 `confirmedItems`。每项保留 artifact ID、交付 ID、交付版本、验收人和时间。界面进一步与正在查看的交付版本匹配。未验收、退回、完成记录失效或跨作用域内容不能供给确定事项。

这证明事项是“来自已验收交付的事项声明”，不声称用户逐项确认，也不通过全文正则从模型回复、验收备注或普通 JSON 猜测用户确认。持久 store schema 和可信 `MemorySource` 类型不扩大，模型不能自行增加用户确认来源。

## 独立演示与真实项目保护

演示资料、成果、关系和验收记录必须明确标注“演示／模拟”，放入独立演示工作流实例、会话及知识空间。模拟验收使用明确的演示验收人和说明，不伪造真实用户确认、真实原生消息或真实项目的验收历史。演示数据是人工编排，不通过模型生成；上传、整理或资料展示也不得暗中调用模型。

真实工作流实例的当前步骤、完成记录、默认／会话选择、员工配置和知识保持原样。演示新增对象可能增加整体状态 revision 和对象数量，因此要将“安装更新前后保留验证”与“受控新增演示后的差异允许清单”分别记录，不能把有新增演示对象的状态宣称为整个文件字节不变。只有报告证明在允许范围内新增且真实对象不变，才计为演示隔离通过。

演示脚本先在副本预检，正式执行绑定实际获授权的新原生会话和当前 revision。重复执行可识别已有演示，不重复复制同一套员工、团队或知识引擎；没有改用真实实例来填充演示界面。最终离线执行、允许差异与模型调用计数见下方正式本地记录。
