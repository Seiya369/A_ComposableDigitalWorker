## 功能验证及实际边界

最终代码完成 typecheck、build、166 项测试和 `git diff --check`。领域测试覆盖并行及汇合、暂停、局部重试、依赖与项目隔离、版本变化只影响相关后继、重启不重放、原子回滚和工作流生成独立任务。真实官方 Agent/preset/工具的脚本模型测试覆盖权限检查、已安装 Skill 按人员选择、未选 Skill 拒绝、文件文本快照、二进制/超限引用标记及默认 AGENTS/subagent hooks 不进入人员执行；不调用生产模型或外部网络。

项目工作台提供工作总览、任务列表/看板/依赖图、成果版本关系图与原生执行会话导航。能力编辑器保留项目协作与记忆工具的明确选择及草稿授权，保存前不改实际人员权限。已有人员、团队、顺序工作流和 `@` 独立工作单继续保留；工作台状态使用可选 `workState`，旧状态不会因为启动而自动创建任务或放宽权限。JSON v1 交换仍仅覆盖人员、团队和工作流配置，不交换项目目标、任务、成果版本和执行记录。

本轮归档验收使用人工成果完成项目、用未注册模型制造本地失败，没有使用外部模型账号完成真实项目；因此不把这些结果声明为模型产出质量、真实用量或项目完成率实验。Bash/终端与未适配第三方工具仍不开放。原生文本文件工具保留有界内容快照，人工只填路径、二进制、超限或不能安全读取的成果仍是路径引用，不能声称其内容历史可回放。

## 清理边界

普通卸载保留插件业务数据，完整清理仅在显式选择后执行。原生人员会话属于宿主共享历史，用户项目和交付成果文件均保留；不直接修改宿主 session 或 credentials 存储，不声称消除宿主历史中的全部痕迹。自建服务和日志清理由显式 `--service-root` 定位；本次隔离生命周期未创建或移除真实用户 launchd 服务。后续随包文件如有改变，必须重新打包、核对新哈希并重新执行归档验收。
