## 适用边界

本次验证证明以上宿主基线加补丁后的兼容性，不代表所有 Harness 版本均兼容。安装包更换以重启和刷新为生效边界；不承诺运行中无刷新热更换 npm 包。通用插槽补丁属于本地宿主扩展，尚未宣称上游已发布这些接口。

完整浏览器回归 `DSH_SNAPSHOT=replay pnpm run test:web` 的最后一轮有 280 项通过、15 项跳过，另 1 项暴露了原测试只接受官方品牌、拒绝本地构建的问题。该断言已按实际构建记录修正；随后将构建启动、后台任务列表、设置界面三个文件一起复测，13 项全部通过。后台任务和设置截图的两处就绪竞争也已改为等待明确的界面状态，未修改期望截图。修复后没有再重复整套浏览器运行；全量中其余用例的实现未再改动。
