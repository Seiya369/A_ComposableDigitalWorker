## 本轮行为与语义边界

默认在一张完整画布中显示全部有证据的概念、实体及其真实关系，取消矩形分组包络与重复组标题。连通分量、知识分组和类型仍可用于元数据及着色；分组不再形成各自独立缩放的盒子。孤立节点和互不连通的知识仍保留，不为视觉整体感补边。

主图继续只接收 `concept/entity` 节点。文章、来源、概览仍用于正文阅读和证据回查，不加入语义画布。无向绘制及可达搜索不改变每条关系原有的方向、谓词、`explicit/inferred`、文章条目或精确来源引用；共享页面、共同来源、社区颜色及文字共现均不能生成关系。阅读入口和页面数量不改变图谱拓扑或统计。

点击概念／实体时保留既有真实一跳高亮，右侧显示概念说明、关联正文入口及证据，其他背景节点淡化；打开关联文章即可阅读完整知识正文并保留图谱上下文。首次点击“展开关联”以起点和可见真实一跳组成探索集合，并适配到该子图；因此已经完整的一对节点也能进行首次适配。后续每次点击只沿当前集合的真实边增加一个 BFS 层级，集合内展示真实的诱导边。没有新邻居时显示并禁用“已展开全部关联”；孤立节点显示并禁用“暂无关联”。

浏览、搜索、着色、展开及相机适配只改变内存中的显示状态，不调用模型、重编知识或持久写入。原始资料上传与知识编纂仍按既有严格增量规则处理，与本轮浏览动作分开验证。

## 状态保持与重置

| 操作 | 探索、阅读和相机行为 |
| --- | --- |
| 同一起点打开关联文章或精确来源 | 保留探索起点、已达节点集合和上下文，可返回图谱及正文 |
| 悬停节点或切换知识分组／节点类别着色 | 不替换已展开集合，不改变真实边或已拖动坐标 |
| DSH 中文／English 实时切换 | 固定文案随语言更新，用户名称、知识正文、关系证据及现有探索保持原文和状态 |
| 搜索或类型筛选变化 | 退出当前探索；可见集合参与后续初始化与扩展，不跨越被隐藏的桥接节点 |
| 选择不同概念／实体或关系 | 退出旧探索，恢复该起点的一跳语境或关系证据 |
| “返回全图” | 清除焦点、阅读、搜索和类型筛选，恢复全图相机；保留当前着色方式 |
| 切换知识空间、快照版本或绑定代际 | 清除旧选择、探索、来源请求、搜索与类型筛选，恢复默认知识分组着色 |

Sigma 与 SVG 备用画布使用同一可见集合和真实关系规则。展开适配允许相机在集合扩大后缩小视图；打开／关闭正文、画布变宽变窄或再次适配均保留用户拖动后的世界坐标。修后强复现将节点拖出初始世界包络，再打开／关闭正文及点击适配，两个渲染器的世界坐标均保持，所有可视节点仍位于留有 28px 边距的画布内。见下方源码组件专项；它与最终归档原生浏览器回归分别记录。

## 共享程序与官方扩展边界

沿用一套包级 `third_party/llm-wiki/`、一份编译引擎和沙箱网页，各员工和团队只持有隔离的知识空间、资料与快照，不复制整套程序。运行时继续按需共享至多一个受管引擎进程。详情见 [共享 Wiki 接入规格](../docs/architecture/shared-llm-wiki.md)。

沙箱只使用父界面已经授权的视图、只读来源请求及原有绑定协议；没有增加宿主接口、凭据访问、任意本机文件读取或持久写接口。源码与正式安装均不要求修改 Harness；监听、相机、观察器、图渲染实例及引擎进程沿既有插件生命周期清理。
