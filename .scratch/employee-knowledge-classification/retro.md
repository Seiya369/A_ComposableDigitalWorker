# 本轮轻量复盘

来源：本次研究、真实 red/green、独立审查与验收；不读取其他会话或用户知识库。

1. **官方环境的假通过风险。** 原来缺包会回落到祖先目录中的源码。现在根锁文件支持普通 npm ci，setup 检查完整公开类型和 realpath，官方生命周期另核对 31 项生产 peer；CI 执行这些门。后续环境问题先按 `ci/README.md` 定位，避免重新摸索或关闭 peer 检查。
2. **检查脚本与实际接口的漂移。** 新 strict 门覆盖全部 TypeScript 测试及脚本，修正旧 fixture 的真实签名；打包门两次 npm pack 并比较每个源文件字节。文档中的旧安装绕过命令也已修正。无需为已自动检查的规则继续膨胀 AGENTS.md。
3. **生命周期夹具也要保留实际失败。** 真实 pnpm 长路径失败单独保存；验收使用同哈希的临时短路径副本，保留至重装和清理结束。正式安装文档明确长期 `file:` 来源不能提前删除。
4. **把确定性与语义检查分开。** 行引用、类别、政策身份和原件出口有确定性测试；两组语义样例另由独立上下文复核，并保留两处引用提示。后续评估使用同一输入/输出哈希和权限边界，而不让模型自评代替证据。

本轮未加入泛化的额外工作规则，也未切换预算默认或升级用户 profile。待用户确定历史基线的远端发布范围后，才可将本地 CI 门映射到实际远端运行和合并记录。
