# 故障定位与恢复

读取实际错误、相关版本、执行条件和最小复现，不根据摘要猜测根因。沿输入、状态、边界、依赖和输出逐步验证假设，一次改变一个有依据的因素；区分产品缺陷、环境问题和权限缺失。

定位后采取本任务范围内的最小修复，重跑复现及受影响检查。涉及持久化或外部写入时先确认当前状态、幂等和恢复路径，不能盲目重试导致重复操作。已有产物、用户数据和凭据按原归属保留，不为排错关闭保护或扩大权限。

记录触发条件、根因依据、修正差异、恢复结果和剩余限制。无法继续时给出已排除项和具体阻塞。不得自行启动生产部署；若曾使用本任务临时工作树，完成合并核验后执行 `worktree-cleanup`，有残留必须报告。
