# 流水线与自动化

读取现有项目命令、CI 配置、触发条件、产物和部署流程，复用已经有效的检查。针对本次问题补齐必要的构建、测试、缓存、产物校验及失败反馈，不重复引入另一套流水线。

明确每个作业需要的输入、最小权限、超时、并发与重试条件；凭据留在现有密钥管理中，不输出到日志或打包产物。隔离测试和正式数据，外部发布使用项目已有授权门槛。

在允许的临时环境或验证入口检查语法、任务依赖、失败场景和产物。缓存键与依赖版本相容，缓存不能掩盖失败。任务完成和异常退出都停止自建服务，归还占用资源；本任务的临时工作树合并验证后调用 `worktree-cleanup`，核查磁盘与 Git 记录无残留。交付差异、实际运行证据、恢复办法及尚待外部环境验证的部分。
