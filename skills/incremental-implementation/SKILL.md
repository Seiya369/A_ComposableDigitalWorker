# 增量实现

先读取本工作单、已有规格、相关真实代码和项目约束，确认本次范围、输入、交付内容与验收标准。已经明确的决定直接沿用，不重新访谈或拆解整个项目。只缺关键前提时提出具体问题，其余注明假设后推进。

按可独立验证的小块实现，尽量复用现有接口和组件；每块完成运行与改动相称的检查。修复应提供可复现问题和有效回归证据；界面变化检查实际运行效果。记录执行命令、结果、未执行项和剩余风险，不用自检代替独立测试与人工验收。

只有任务确需隔离才创建临时工作树，不为小改动强制创建。创建后立即登记本任务所有权、路径、分支和集成目标；使用 `worktree-cleanup` 技能完成登记与收尾。合并并验证后必须移除本任务临时工作树，连同可再生依赖和构建目录，复查磁盘路径与 Git 工作树列表；不得仅合并提交后留下目录。未合并成果或用户文件先保全，禁止强删、清理其他任务工作树或丢弃用户修改。收尾失败报告路径、原因和保全位置，任务不能声称已完整收尾。

提交可审查差异、实际成果引用及验证结果；提交、推送、发布和部署依照本次任务已有授权，不因加载此技能获得额外授权。
