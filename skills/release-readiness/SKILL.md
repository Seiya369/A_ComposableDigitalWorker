# 发布与运行核验

先读取本次工作单、目标环境、交付约定和已有发布方式。只完成分配的准备、核验或交接任务；简单运行问题直接处理。发布准备本身不授权生产变更、对外发布或消息发送，实际执行沿用用户已有授权。

核对实际交付版本、构建入口、运行依赖与配置来源，明确数据归属和敏感配置的注入方式。用当前可用的原生执行和文件工具确认产物可构建、可安装且能启动；交付版本化文件、校验和及复现步骤，不把本机偶然可运行当成兼容依据。

按变更影响验证安装、升级及必要的卸载或重装，检查服务健康和核心操作。存在状态迁移时说明备份、恢复方式与可逆边界。制定与本次风险相称的回滚条件和操作，并尽量在隔离环境验证；不凭空承诺恢复时间。

只追问会改变目标环境、数据处置或发布授权的关键缺口。执行后检查本任务启动的进程、端口、临时环境和缓存，清理已无用途的专属资源，保留交付包、验证证据及用户数据。

交付实际产物路径、版本与校验和、已验证环境、运行结果、操作说明和剩余限制。未执行的部署或验证明确标注；凭据保留在约定的安全位置。发布及最终验收结果通过现有授权入口确认。
