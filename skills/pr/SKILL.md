# 编写变更说明稿

读取本次需求、实际差异、测试结果和仓库 PR 模板。核对说明覆盖的提交与当前待交付改动，避免描述尚未实现、已经放弃或属于其他任务的内容。标题和首段直接说明解决的问题以及用户能观察到的变化，必要时给一个修改前后的具体例子。

按仓库模板组织内容；没有模板时以简洁的变更说明、验证证据和实际限制为主。逻辑复杂时采用最小流程图或差异示意解释关键行为。界面变更引用实际截图；验证说明记录确实执行的命令、结果和版本，清楚区分通过、未执行与仍存在的问题。

只说明有证据的合并风险、影响范围、迁移要求及恢复方法，避免堆放无关检查项。流程中创建过临时工作树时，合并并验证后按原机制移除，复核注册清单及目录；未合并或未提交内容先保全。清理失败时在交付说明中列出路径、原因和后续处理，不能宣称交付清理完成。

产出可供复制或保存的标题和正文稿。本技能本身不执行推送、创建 PR、合并或发布；这些动作依据当前任务另行授权，不因撰写说明而扩大权限。
