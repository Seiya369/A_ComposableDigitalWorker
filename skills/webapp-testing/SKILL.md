# Web 应用验证

从任务的验收标准列出关键路径、风险边界和应保留旧行为。先确认待测版本、地址及隔离数据，使用当前实际可用的浏览器或项目已有端到端框架；不假设安装了特定 MCP、Python 库或全局浏览器工具。

等页面达到可交互状态后检查实际 DOM 或截图，再基于可观察的标签和状态定位操作。验证输入、提交、持久化、空白、失败、权限、危险操作取消、窄屏与必要键盘路径；按改动选择检查范围，不机械运行全套无关场景。检查浏览器运行错误，截图保留页面上下文。

每项记录条件、操作、预期、实际、版本和证据。未执行、阻塞与失败分别列出；代码审查用于发现覆盖缺口，不能当作已执行的界面测试。不得操作未授权生产数据、关闭用户浏览器或把外部操作视为测试授权。

仅停止本测试创建的服务和浏览器。若另行创建隔离工作树，合并验证后按 `worktree-cleanup` 清理，报告剩余进程或目录。
