# 设计体系参考

根据用户、产品场景、内容密度与现有品牌，确定必要的布局、字体层级、颜色语义、间距、控件状态与图表表达。给出少量有依据的取舍，不用大量风格选项替代决定。

以现有组件库和产品约束为起点，必要时形成一份共享规范及页面例外，避免每页或每位员工生成重复规范。选择需满足内容可读、键盘操作、对比度与窄屏适配。不要为风格展示改动既有功能或引入无关装饰。

本技能是 DSH 的轻量设计指导，不含外部 `ui-ux-pro-max` 的搜索数据库或脚本；不得虚构已检索库、实际测量或验证。需使用外部设计资料时真实读取并注明出处。交付规范或示例及待验证点，使用任务指定的文件位置，普通咨询直接回答。
